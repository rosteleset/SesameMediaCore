# Source provenance

The initial standalone workspace was extracted from the shared native crates in
SesameDVR commit `cfc79a5c54740554bc4fd2a9fa9e4375949b1683` on the
`elexir-webrtc` branch. The same crate sources were present in SesameAgent
commit `fbfcf7ee47576e862da1ffadb08c0176373c8f04`.

The repository starts from a clean snapshot so unrelated SesameDVR and
SesameAgent history is not exposed through the shared library repository.
